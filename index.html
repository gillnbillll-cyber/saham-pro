Aturan interpretasi

  • Harga naik + volume di atas rata-rata: aktivitas beli mungkin meningkat, tetapi belum membuktikan akumulasi.
  • Harga turun + volume di atas rata-rata: tekanan jual mungkin meningkat, tetapi belum membuktikan distribusi.
  • Konfirmasi membutuhkan data broker summary, transaksi, likuiditas, berita, dan konteks pasar.

News Scanner → Telegram

Frontend ini belum mengirim Telegram secara langsung karena token bot harus dirahasiakan. Gunakan Apps Script backend di folder apps-script untuk memeriksa feed berita secara berkala dan mengirim alert.

Checklist integrasi gratis
  1. Buat bot melalui @BotFather dan simpan token sebagai Script Property.
  2. Ambil Chat ID dengan mengirim pesan ke bot lalu cek endpoint getUpdates.
  3. Tambahkan feed RSS tepercaya di Apps Script.
  4. Pasang trigger waktu (mis. setiap 15 menit); feed publik bisa terlambat dan tidak menjamin semua berita tercakup.

Jangan menaruh token Telegram di HTML, GitHub publik, atau membagikannya kepada orang lain.
